# MU:D ARCHIVE

MU:D ARCHIVE — Emotion Archive & Content Studio.

## Current version
A lightweight static content studio prototype for developing MU:D ARCHIVE card-news.

## Structure
- `index.html` — studio interface
- `styles.css` — MU:D ARCHIVE visual system
- `app.js` — card-news preview and interaction
- `cardnews/` — future exported card-news
- `assets/` — images, logos, fonts
- `templates/` — reusable content templates

## Vercel
This repository is designed to be deployed as a static site on Vercel. No build command is required for the current prototype.

## Direction
1. Input the message.
2. Structure the story.
3. Generate card copy.
4. Apply MU:D ARCHIVE design.
5. Edit individual slides.
6. Export 1080×1350 PNG cards.
